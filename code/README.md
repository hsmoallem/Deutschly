# Deutschly Application Source Code

This folder contains the complete Next.js 14 full-stack application for Deutschly.

## Quick Start

```bash
# 1. Install dependencies
npm install
pip3 install gTTS simplemma pytesseract pillow

# 2. Run automated tests (29 assertions)
npm test

# 3. Start development server
npm run dev
```

The application will run at [http://localhost:3000](http://localhost:3000).

Default login:
- Student: `student` / `password123`
- Admin: `admin` / `password123`

For architectural specifications and product requirements, see `../documentation/`.
